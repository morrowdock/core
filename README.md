# core

Early preview — no stable release or compatibility promise yet. Fresh history; selected source only. Code: Apache-2.0 ([LICENSE](LICENSE), [NOTICE](NOTICE)). Names, mascot and logos are not licensed ([TRADEMARKS.md](TRADEMARKS.md)). Contributions need a DCO sign-off ([CONTRIBUTING.md](CONTRIBUTING.md)).

Run: `swift test`. `Composition/` refers to this package by its folder name, so keep the checkout folder named `core` (the default for `git clone`). Linux CI runs on pushes and pull requests; execution status is recorded in GitHub Actions. macOS: run the same command with Swift 6 / Python 3.12 as applicable. Apple UI renderers and app/device acceptance are outside this portable slice.

Includes CourseBundle v1 validator, terminal simulation, Python learning/mastery rules, open service interfaces and synthetic network clients. Run learning tests with `python3 -m unittest discover -s learning/tests`. Course catalog/project v1 subset contracts are preparatory; full production migrations remain pending. Plus is optional; no provider keys/private package needed.
